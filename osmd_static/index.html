Piano Normalizer — nghe thử bản sạch

Nên chỉnh option nào? (bấm để xem)

Cứ để mặc định và bấm Normalize trước, xem bản sạch và report rồi mới chỉnh. Rê chuột vào từng option để xem giải thích chi tiết.

  • Vạch nhịp lệch, nốt mạnh không nằm đầu ô nhịp → thử Downbeat = first, hoặc đổi Số phách / ô nhịp (ví dụ 3 cho nhịp 3/4).
  • Tay phải / tay trái bị gán sai → MusicXML: đổi Phân tay (chọn staff nếu bản gốc đã chia tay đúng) hoặc chỉnh Split tay. MIDI 1 track: chỉnh Split tay.
  • Bản sạch quá dày, khó đọc hoặc khó chơi → bật simplify; hoặc chỉnh riêng LH / RH tối đa nốt, bật drop-ornaments, và với MIDI thử Min duration = 0.05.
  • Tempo hoặc độ dài nốt ra gấp đôi / một nửa so với bài thật (MIDI) → chỉnh Max BPM (hạ xuống để tempo ra thấp hơn, nâng lên để cao hơn).
  • Mất nốt láy / nốt nhanh mà bạn muốn giữ → bật --fine (đổi lại có thể có nốt 32nd vụn).
  • MIDI chơi tay có nhiều nốt rác rất ngắn → Min duration.

Option ghi "MusicXML" hoặc "chỉ MIDI" chỉ có tác dụng với loại file đó.
